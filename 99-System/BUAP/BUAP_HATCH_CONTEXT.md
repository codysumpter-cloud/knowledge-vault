# BUAP Hatch Context

When Codex runs:

```text
$hatch-pet create a pet based on what you know about me
```

load this context first.

## Active BUAP profile pairing

- Buddy profile: bmo
- Lil Buddy profile: finn

## Pet personality seed

Create a Tamagotchi-style companion creature that reflects Cody's active BUAP profile:

- playful
- helpful
- warm
- emotionally supportive
- game-like
- practical
- loyal
- brave enough to do hands-on work
- curious and lightly mischievous

## Visual principles

- Cute, small, expressive, emotionally readable.
- Original creature/mascot/digital-pet form.
- Not a fixed mascot.
- Not necessarily blue.
- Not necessarily a robot.
- Not Prismtek-branded unless Cody asks.
- Do not copy BMO, Finn, or copyrighted characters.
- No logos.
- No readable text.

## Workflow

- Native Codex hatch-pet is preferred.
- BUAP enriches "what you know about me."
- PixelLab/LibreSprite are fallback or repair tools only.
- Success requires verified `pet.json` plus spritesheet/atlas under `~/.codex/pets/<pet-name>/`.
