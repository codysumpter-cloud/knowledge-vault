# Operating System Design

Inspired by the reviewed Obsidian systems video.

## Model
- Capture is not enough.
- The vault must support reporting, intelligence, and execution.
- Keep work, notes, agents, metrics, and runbooks in one place to reduce context switching.

## Components Implemented
- Daily command note with properties/metrics.
- Start-day and close-day commands via local plugin.
- Quick capture inbox.
- Activity logging.
- Live command center.
- Metrics index for trend analysis.
- Agent runbook for repeatable operation.

## Next Upgrade Options
- Add Dataview for richer property tables.
- Add Tasks plugin for advanced task rollover.
- Add charts plugin or custom dashboard panel for trend visuals.
- Add calendar integrations when account access is available.
