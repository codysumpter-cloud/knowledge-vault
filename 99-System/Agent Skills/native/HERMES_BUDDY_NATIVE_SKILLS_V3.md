## Source adaptation notes

These skills adapt prior Buddy/Hermes planning, public content automation inspiration, model-review inspiration, and Hermes-style skill formatting into native `SKILL.md` files. The public repo copies intentionally avoid storing credentials, cookies, tokens, private account data, or execution instructions for regulated domains.

## Guardrails

No credential use, no cookie persistence, no auto-posting, no DMs, no mass outreach, no repo mutation without approval, no destructive memory operation, and no claim that external work happened unless an approved adapter confirms it.
