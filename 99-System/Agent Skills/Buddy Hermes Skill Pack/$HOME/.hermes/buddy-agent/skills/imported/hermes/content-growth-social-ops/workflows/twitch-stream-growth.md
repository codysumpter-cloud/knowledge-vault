# Twitch Stream Growth Workflow

## Purpose

Help streamers plan, promote, clip, and repurpose Twitch streams.

## Pre-stream

Create:

- stream title
- category/game selection notes
- 3 social promo posts
- cold open
- first 10-minute run of show
- viewer participation hook
- clip targets

## During stream

The agent may suggest:

- moments to clip
- chat prompts
- segment transitions
- recap notes

The agent must not moderate, ban, timeout, or message users without explicit approval and an adapter.

## Post-stream

Create:

- recap post
- clip shortlist
- YouTube Shorts plan
- X thread
- Discord/community summary
- next stream teaser

## Stream title formula

```txt
[Specific build/challenge] + [stakes] + [community invitation]
```

Examples:

```txt
Building a tiny AI clip machine — chat picks the prompts
Hardcore pixel-art boss design — one stream, one finished enemy
React migration cleanup — turning chaos into components
```

## Clip criteria

Prioritize clips with:

- visible emotion
- clear before/after
- funny failure
- satisfying solve
- teachable moment
- strong opening line
