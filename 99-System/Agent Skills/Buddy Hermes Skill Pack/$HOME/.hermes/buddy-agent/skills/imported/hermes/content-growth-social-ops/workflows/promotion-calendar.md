# Promotion Calendar Workflow

## Purpose

Create a lightweight promotion plan that does not spam.

## Inputs

- launch/content date
- platform list
- audience
- CTA
- assets
- posting limits
- approval mode

## Calendar shape

```txt
T-3 days: teaser
T-1 day: context / problem
T day: launch post
T+1 day: lesson learned
T+3 days: result / clip / proof
T+7 days: recap / evergreen version
```

## Safety limits

Default maximums:

- X: 1-3 original posts/day per campaign
- YouTube Shorts: 1/day until stable
- Twitch: 1 pre-stream + 1 live + 1 recap per stream

Do not mass-DM.

Do not spam replies.

Do not repeatedly mention unrelated accounts.

## Output

Return:

- calendar
- draft copy
- assets needed
- approval checkpoints
- risk notes
