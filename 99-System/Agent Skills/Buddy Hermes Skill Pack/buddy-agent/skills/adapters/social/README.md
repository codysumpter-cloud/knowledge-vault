# Social Adapter Contract

Supports YouTube, X, and Twitch.

## YouTube modes

- channel/content audit
- Shorts metadata generation
- upload checklist
- scheduling draft
- analytics iteration
- publishing through approved backend only

## X modes

- post/thread draft
- hook generation
- quote-post angle draft
- launch calendar
- reply strategy draft
- publishing through approved backend only

## Twitch modes

- stream title/category draft
- stream promo plan
- clip repurposing plan
- post-stream recap
- raid/collab shortlist
- account action through approved backend only

## Hard blocks

- fake engagement
- bot replies
- mass unsolicited DMs
- harassment
- impersonation
- engagement pods
- evading platform rate limits
- posting without explicit approval
