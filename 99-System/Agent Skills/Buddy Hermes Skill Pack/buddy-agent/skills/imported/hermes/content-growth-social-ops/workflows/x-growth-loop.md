# X Growth Loop

## Purpose

Create high-signal X posts and threads that support content launches, build-in-public updates, and community growth.

## Modes

- single post
- thread
- quote-post angle
- launch post
- reply draft
- recap post
- content-to-X repurpose

## Default strategy

```txt
1. Find one sharp claim.
2. Make the first line specific.
3. Add proof or texture.
4. Invite replies without baiting.
5. Keep the post skimmable.
6. Draft 3 variants.
7. Preview before publishing.
```

## Hooks

Good hooks usually contain:

- surprising contrast
- concrete number
- mistake avoided
- result achieved
- practical lesson
- strong opinion with caveat

Avoid:

- engagement bait
- fake scarcity
- rage bait
- vague hype
- stolen phrasing

## Thread structure

```txt
1. Hook
2. Problem
3. Stakes
4. System
5. Example
6. Takeaway
7. Soft CTA
```

## Approval gates

The agent may draft replies and posts.

The agent must not:

- post
- reply
- quote
- repost
- DM
- follow/unfollow
- change profile

without explicit approval and adapter execution.
