# Cross-Platform Repurpose Loop

## Purpose

Turn one source asset into native content for YouTube, X, and Twitch.

## Input types

- Twitch VOD
- YouTube Short
- long-form YouTube video
- screen recording
- product demo
- blog post
- changelog
- devlog

## Output map

```txt
Source idea
→ YouTube Short
→ X post
→ X thread
→ Twitch stream segment
→ community post
→ follow-up experiment
```

## Repurpose checklist

For every output:

- keep the native platform format
- rewrite the hook
- avoid reposting identical copy everywhere
- preserve source attribution
- log asset usage
- avoid duplicate posting too soon

## Example

```txt
Source:
A 20-minute Twitch segment about building Buddy skill adapters.

YouTube Short:
"Why AI agents need adapters, not unlimited permissions"

X post:
"The safest AI agent architecture is boring: registry, policy, adapter, log."

Twitch follow-up:
"Tonight: turning the adapter sketch into a real skill runtime."
```
