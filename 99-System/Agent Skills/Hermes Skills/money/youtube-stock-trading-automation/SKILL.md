# YouTube Stock Trading Automation

## Overview

When the user wants to automate YouTube content creation and use profits for stock trading, prefer building a custom, streamlined system over wrestling with complex existing frameworks like MoneyPrinterV2. This approach is faster, more maintainable, and avoids dependency hell.

## Trigger Conditions

- User explicitly requests YouTube automation + stock trading integration
- User expresses frustration with complex system setup
- User wants quick operational capability

## Approach

### 1. System Architecture
```
- Core Python script orchestrating workflow
- Video generation with moviepy
- YouTube Data API v3 for uploads
- Stock trading API (Alpaca recommended for paper trading)
- Simple configuration file
```

### 2. Implementation Steps

**A. Set up environment**
```bash
# Create project structure
mkdir -p ~/money-printer-v2-custom/{scripts,config,logs,output,videos}

# Create virtual environment
python3 -m venv ~/venv/money-printer-v2
source ~/venv/money-printer-v2/bin/activate

# Install core dependencies
pip install moviepy pandas tabulate google-api-python-client oauth2client alpaca-trade-api yagmail
```

**B. Install system dependencies**
```bash
# macOS
brew install ffmpeg geckodriver

# Ubuntu/Debian
sudo apt-get update && sudo apt-get install -y ffmpeg gecko-driver
```

**C. Create configuration**
- `config.json` with YouTube API key, channel ID, Alpaca keys
- Store in `~/money-printer-v2-custom/config/`

**D. Implement core modules**
- `video_generator.py` - creates YouTube Shorts
- `youtube_uploader.py` - handles API upload
- `stock_trader.py` - connects to Alpaca
- `main.py` - orchestrates workflow

**E. Run the system**
```bash
cd ~/money-printer-v2-custom
source ~/venv/money-printer-v2/bin/activate
python scripts/main.py
```

## Workflow

```
Generate video → Upload to YouTube → Wait for monetization → Allocate earnings → Execute stock trade
```

## Verification Steps

1. Test video generation: `python scripts/video_generator.py`
2. Test YouTube upload with sample video
3. Verify Alpaca connection and balance
4. Run full workflow with test credentials

## Pitfalls & Solutions

### Dependency Hell
- **Problem**: Complex systems like MoneyPrinterV2 have many fragile dependencies
- **Solution**: Build custom system with only essential packages
- **Prevention**: Start simple, add features incrementally

### YouTube API Limitations
- **Problem**: API keys may not have YouTube Data API enabled
- **Solution**: Direct user to enable API in Google Cloud Console
- **Prevention**: Include enablement link in configuration instructions

### Alpaca API Integration
- **Problem**: Paper trading vs live trading confusion
- **Solution**: Default to paper trading, clearly label in config
- **Prevention**: Use environment variables for sensitive keys

### Video Generation Complexity
- **Problem**: Creating engaging content automatically is hard
- **Solution**: Start with simple text-on-video, iterate based on results
- **Prevention**: Use placeholder content initially, upgrade later

```json
    "min_balance_for_trading": 100
  }
}
```
