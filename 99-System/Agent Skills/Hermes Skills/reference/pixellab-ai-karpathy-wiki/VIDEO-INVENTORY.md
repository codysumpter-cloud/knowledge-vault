## Learning map by video theme

### Base images and style

Relevant videos:

- `h0D-oVAFdMs`
- `Tbmfh4pBPeo`
- `iBMq3P_Fazk`
- `68BYzLoLh-U`
- `XhmpenTmPLg`
- `moCpjMOOBGk`
- `a_ygRPpBmnI`

Durable learning:

- establish a canonical style and identity reference before expanding the asset set
- use inpainting to preserve accepted regions
- treat palette, projection, direction, outline, shading, and detail as explicit controls
- generate variations, select globally strong structure, then repair locally

### Directional characters and states

Relevant videos:

- `ufQ72nGORC0`
- `T4by1uEXuE4`
- `oCJWxfEwX-o`
- `ptWw9gkgorQ`

Durable learning:

- directions are related views of one identity
- state and outfit changes should preserve body, direction, and frame topology
- approve a canonical frame or direction before batch propagation
- validate row order and handedness in a compass preview

### Animation

Relevant videos:

- `RVVuDhyEbRI`
- `mlCa0UdAhow`
- `ptWw9gkgorQ`
- `owkamgYVWAs`
- `1CjxHZoZE_I`
- `H98R_o2nw30`
- `wijMirHw6QQ`
- `oCJWxfEwX-o`
- `moCpjMOOBGk`

Durable learning:

- meaningful key poses and reusable skeletons matter more than raw frame count
- accepted frames should be frozen and used as guidance for repairs
- animation-to-animation transfers motion structure but still requires skeleton and frame inspection
- interpolation is a finishing operator, not a substitute for motion design
- attack effects need deliberate spatial room and action phases

### Tilesets, maps, and scenes

Relevant videos:

- `CuBvG9mfQng`
- `H-dPJKmKr1E`
- `jPPznIEK7HY`
- `O9maOTbLuHQ`
- `1FWEXTiJnlc`

Durable learning:

- tilesets encode adjacency and transition rules
- maps should be built region by region with init images and frozen context
- test every edge and corner arrangement before accepting a tileset
- animated scenes still require stable tile boundaries, loops, and gameplay readability

### Agent-assisted game production

Relevant video:

- `THwZYWuOdZI`

Durable learning:

- PixelLab can be exposed through MCP to coding agents
- generation becomes useful when the agent also preserves metadata, asset identity, topology, and validation receipts
- a generated asset is not integrated until the actual game runtime verifies it
