# Content Growth Guardrails

## Allowed

- Draft posts, titles, descriptions, and scripts.
- Suggest hooks and content angles.
- Build a content calendar.
- Analyze public metrics supplied by the user.
- Create testable hypotheses.
- Prepare post previews.
- Log content inventory.
- Suggest manual publishing steps.

## Requires explicit approval

- Publish content.
- Schedule content.
- Reply, comment, quote, repost, or DM.
- Change profile/account settings.
- Use paid promotion.
- Delete or edit existing posts.
- Access private analytics through an authenticated account.
- Connect/disconnect social accounts.

## Hard blocks

- Fake engagement.
- Bot accounts.
- Engagement pods.
- Mass unsolicited DMs.
- Harassment campaigns.
- Impersonation.
- Misleading sponsorship/affiliate claims.
- Plagiarism.
- Copyright-unsafe reuse.
- Platform rate-limit evasion.
- Promises of guaranteed virality.

## Safer default

When asked to "go viral", convert the request into:

```txt
Make the content more likely to earn watch time, shares, saves, replies, and click-throughs while staying platform-safe.
```

## Required quality check

Before previewing a post:

- Does the hook create curiosity without lying?
- Is the CTA clear?
- Does it match the platform?
- Is there a specific audience?
- Is the asset reused safely?
- Is there anything that could trigger account risk?
