# Hugging Face Gemma 4 Setup for Hermes Agent

This reference documents the exact steps taken to configure Hermes Agent to use a Gemma 4 model from Hugging Face.

## Prerequisites
- A valid Hugging Face token with at least `read` scope (created at https://huggingface.co/settings/tokens)
- Hermes Agent installed and configured

## Steps

### 1. Add the Hugging Face credential to Hermes
```bash
hermes auth add huggingface --api-key hf_YOUR_TOKEN_HERE
```
This stores the token securely in Hermes' credential pool (under `~/.hermes/auth.json`).

### 2. Verify the credential was added
```bash
hermes auth list
```
You should see a `huggingface` section with your credential listed.

### 3. Set the provider to Hugging Face
```bash
hermes config set model.provider huggingface
```
This updates `~/.hermes/config.yaml`:
```yaml
model:
  provider: huggingface
```

### 4. Set the default model to a Gemma 4 variant
First, confirm the model exists on Hugging Face (optional but recommended):
```bash
curl -s "https://huggingface.co/api/models?search=gemma+4&author=google&limit=1"
```
Then set it:
```bash
hermes config set model.default google/gemma-4-31B-it
```
This updates `~/.hermes/config.yaml`:
```yaml
model:
  default: google/gemma-4-31B-it
  provider: huggingface
```

### 5. Verify the configuration
```bash
hermes config
```
Look for the Model section:
```
◆ Model
  Model:        {'default': 'google/gemma-4-31B-it', 'provider': 'huggingface', 'base_url': 'https://generativelanguage.googleapis.com/v1beta'}
```

### 6. Test the model (optional)
Start a new Hermes session and ask a simple question:
```bash
hermes chat -q "Say hello in one sentence."
```
If configured correctly, the response will be generated by the Gemma 4 model via the Hugging Face Inference API.

## Notes
- The `base_url` shown in `hermes config` may still reflect the previous provider (e.g., Gemini). This is harmless; Hermes will override it with the Hugging Face endpoint when the provider is set to `huggingface`.
- If you do not see the Hugging Face provider in `hermes model`, double-check that the token was added correctly and that you have restarted Hermes (or started a new session) after adding the credential.
- To make this configuration global across all profiles, add `--global` to the `hermes config set` commands, or edit `~/.hermes/config.yaml` directly.
