# iPhone Support Matrix

The iPhone is a cockpit, not the engine room.

## Good on iPhone

- reading and editing notes
- dashboards
- backlinks
- tags
- graph browsing for normal vault size
- Canvas review and light editing
- Tasks
- Kanban
- QuickAdd capture
- Templater templates that do not shell out
- Excalidraw sketch review/light edits
- Juggl if installed and responsive enough

## Desktop/Mac only

- Hermes agent runs
- shell scripts
- local API bridge
- Claudxian
- broad plugin installation
- Git automation
- heavy AI plugins
- embedding/indexing jobs
- repo maintenance

## Recommended profile on iPhone

Use:

`.obsidian/plugin-profiles/mobile-safe.community-plugins.json`

This avoids Git, local APIs, desktop agents, and heavy AI/indexing plugins.
