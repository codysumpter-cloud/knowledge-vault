# Wiki Schema: WorldBox God Sim

## Domain
Knowledge base for WorldBox automation, achievement completion, and modding via AgentCraft/BMO.

## Conventions
- File names: lowercase, hyphens (e.g., `achievement-ninja-turtle.md`)
- Use `[[wikilinks]]` for inter-connectivity.
- Every page must be added to `index.md`.
- All findings must be logged in `log.md`.

## Tag Taxonomy
- Mechanics: achievement, trait, species, kingdom, power
- Technical: nml, bepinex, bridge, api, harmony
- Operation: runbook, risk, verification, strategy
- Meta: guide, reference, roadmap

## Page Thresholds
- Create a page when a specific achievement has a complex recipe.
- Create a page when a technical bridge milestone is defined.
