# BMO Daily Ops

## Morning: `/today`
1. Open Obsidian Command Palette.
2. Run **BMO Ops Dashboard: /today — Start day and build focus note**.
3. Set one current focus and top 3 priorities.
4. Review inbox and yesterday carryovers.
5. Execute one target at a time.

## During Day
- Use **Quick capture to inbox** for ideas/tasks/links.
- Use **Log activity** after meaningful work blocks.
- Keep project state in the vault, not scattered chats.

## Evening: `/close-day`
1. Run **BMO Ops Dashboard: /close-day — Close day with metrics/reflection**.
2. Dictate what happened.
3. Fill metrics properties.
4. Carry unfinished tasks forward.
5. Convert insights into project/runbook updates.

## Agent Rule
Agents should treat this vault as the operating layer: read current dashboard, update durable truth, leave receipts.
