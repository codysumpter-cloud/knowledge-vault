# 📈 Metrics Index

> **Intelligence Layer**: If it isn't measured, it isn't managed. Convert raw activity into trend data.

## 📊 Primary KPIs (Daily Tracking)
*These properties are captured in the `Daily Command Note` and aggregated here.*

| Metric | Definition | Goal | Indicator |
| :--- | :--- | :--- | :--- |
| **Focus Score** | $\text{Deep Work Hours} \div \text{Total Hours}$ | $\ge 0.7$ | High $\rightarrow$ Flow State |
| **Revenue** | Total Daily Profit (YouTube + Trading) | $\uparrow$ | $\text{Cash Flow} > \text{OpEx}$ |
| **Trading PnL** | Daily Delta in Portfolio Value | $\text{Positive}$ | $\text{Alpha Generation}$ |
| **Effort** | Self-reported intensity (1-10) | $\text{Balanced}$ | $\text{Avoid Burnout}$ |
| **Family Time** | Quality hours spent with family | $\text{Priority}$ | $\text{Life Balance}$ |
| **Vault Updates** | Count of durable truth entries made | $\ge 1$ | $\text{Knowledge Compound}$ |

## 🔍 Intelligence Queries
*Analytical questions to run against the vault to find correlation.*

- **Revenue Correlation**: "Which set of daily priorities consistently lead to $\text{Revenue} > \text{Baseline}$?"
- **Focus Optimization**: "Do specific `family_time` or `health` values correlate with a higher `focus_score` the next day?"
- **Execution Velocity**: "Which projects have the shortest time-to-receipt?"
- **Pruning Logic**: "Which recurring tasks result in low `focus_score` and zero `revenue`? $\rightarrow$ **Kill/Delegate**."
