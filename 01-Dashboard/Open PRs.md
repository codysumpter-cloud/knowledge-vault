# Open PRs

This page is the intended home for generated open pull request summaries.

## Current status

Live PR enrichment is not yet generated by Vault Steward. Until that lands, agents should check GitHub directly before making claims about pull request state, mergeability, or CI.

## Manual checklist

For each active repo, capture:

- PR number and title
- branch
- mergeability
- checks status
- risk level
- recommended next action
- whether it blocks a demo or release
