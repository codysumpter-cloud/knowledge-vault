## 🛠️ Receipt Standard
Every entry in a daily log that involves a technical change **MUST** follow this format to be valid:
- **Action**: Clear description of the change.
- **Path**: Absolute path to the file or resource modified.
- **Command**: The exact CLI command executed.
- **Result**: Exit code and summary of the output.
- **Verification**: How the change was proven to be successful.
