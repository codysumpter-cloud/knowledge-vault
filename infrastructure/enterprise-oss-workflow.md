# Enterprise & OSS Workflow

## Overview
Strategic integration of CRM, OSS collaboration, and managed employee frameworks to scale the Prismtek ecosystem from a "Project" to an "Organization."

## Components

### 1. Twenty (Open-Source CRM)
- **Capability:** Version-controlled CRM for managing complex business objects and relationships.
- **Strategic Value:** Acts as the "External Memory" for professional relationships (e.g., Chazz, other modders).
- **Integration Path:** Map "Modder" and "Game Dev" entities into Twenty objects, allowing the Buddy Brain to track the status of partnerships and outreach.

### 2. Oz for OSS (Collaboration Workflows)
- **Capability:** Specialized workflows for human-agent collaboration on open-source software.
- **Strategic Value:** Professionalizes the way we handle PRs and issues in the `buddy-brain` and `omni-buddy` repos.
- **Integration Path:** Implement the Oz "Contribution Loop" for any public-facing Prismtek tools.

### 3. Hermes Paperclip Adapter (Managed Employees)
- **Capability:** Runs Hermes agents as "Managed Employees" within a company structure.
- **Strategic Value:** Allows for the "Departmentalization" of the Buddy Brain (e.g., a "Creative Department" Buddy and a "Technical Department" Buddy).

### 4. Knowledge Forge
- **Capability:** Structured knowledge generation and refinement.
- **Strategic Value:** Automates the process of turning raw data (like the GitHub forks) into the "Knowledge Vault" entries we've been creating.

## Integration State
- [ ] Twenty CRM instance deployed (Cloud or Self-hosted).
- [ ] Oz-style contribution loops implemented for `buddy-brain`.
- [ ] Paperclip adapter configured for departmental agent roles.
- [ ] Knowledge Forge pipelines linked to the `knowledge-vault` CI.
